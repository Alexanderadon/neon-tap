# Фаза 10 — Ритмическая точность («ту ту ТУ») ⭐

Цель: игрок чувствует, что играет музыку сам — слышимая ритмическая фигура фразы повторяется
нота в ноту такт за тактом (как в Magic Tiles), круги идут пока идёт ритм, полосы живут, звёзды
отражают реальную сложность.

## Задачи
- [x] **Профиль фразы.** Для каждой 4-тактовой фразы — среднее усиленной salience по 16 шагам.
  Шаги паттерна = локальные максимумы профиля ≥ 0.4 × максимума (в интенсивных фразах ещё и
  соседи пиков ≥ 0.7 — пары 16-х «та-ка»). Каждый такт получает ноту на шаге паттерна, если
  сам там звучит (сырая сила ≥ 0.05, salience ≥ 50 % профиля). Внепаттерновые удары — только
  очень сильные (≥ 0.85 × максимума фразы: сбивки, стабы). Акценты (шаги ≥ 0.85 × максимума
  профиля, «ТУ») — аккорд из двух полос, если ничего не зажато, иначе крайняя полоса.
  Решения по холдам / слайдам / басовым дробям берутся по (фраза, шаг), чтобы фигура повторялась.
- [x] **Плотность по музыке.** Лимит нот на такт по интенсивности [3 / 6 / 9], скользящий лимит
  на секунду 3 / 4 / 4.5, в интенсивных тактах энергичных песен (средняя интенсивность ≥ 1.2) —
  `DENSITY_LIMIT` 5.5; минимальный интервал 1 слот в интенсивных тактах, 2 — в остальных.
- [x] **Круги по ритму.** Окно кругов — старт интенсивной фразы на 2–4 такта, пока паттерн
  держит ≥ 75 % силы первого такта; круг на КАЖДОМ звучащем шаге паттерна (≥ восьмая между
  ними), нумерация сквозная (движок группирует круги ближе 2.5 с), позиции идут по 8-точечной
  раскладке на всё поле без повторов подряд. Внутри окна и за долю до него обычных нот нет,
  перед сменой полос — те же 2 доли тишины. В песнях ★ ≥ 6 окно может открыть любой старт
  интенсивной фразы, иначе — только границы 8 тактов.
- [x] **Полосы.** Пулы по интенсивности: тихо [2, 3], средне [3, 4], интенсивно [4, 5, 6];
  решение каждые 4 такта в энергичных песнях, иначе 8; сохранить прежнее число — 0.4; интро 4.
- [x] **Звёзды = ощущаемая сложность.** Нот/с (вес 2.2), доля интервалов в 16-ю, пиковая
  плотность за 2 с, доля времени на ≥ 5 полосах, доля слайдов + дробей + кругов, доля аккордов,
  темп. Калибровка по каталогу: самый лёгкий трек ★2–3, самый сложный ★8–9. Каталог сортируется
  по звёздам, затем по нот/с; `genre` и `premium` из реестра проходят насквозь.
- [x] Тесты: повторение фигуры, аккорды на акцентах, ≥ 12 кругов в 4-тактовом окне, пулы полос
  2–6 с 2-долевыми паузами, лимиты плотности, правило двух пальцев, тишина, детерминизм.

## Готово когда
`npm run assets:charts` даёт таблицу с разбросом ★2–9, кругами десятками в припевах и
сменой полос каждые 4–8 тактов; все тесты, tsc, lint и build проходят.
