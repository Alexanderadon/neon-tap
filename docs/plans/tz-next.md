## 5. Сборка для Яндекс Игр (L)

Требования: `yandex.ru/dev/games/doc/ru/concepts/requirements`. Сделать:
- SDK: `YaGames.init`, `LoadingAPI.ready()` при скрытии заставки, `GameplayAPI.start/stop` на забеге, `game_api_pause/resume`;
- звук и радио молчат при потере фокуса и во время рекламы;
- реклама только через SDK (`YandexAds` за интерфейсом `shared/lib/ads`): новинка недели и второй шанс;
- покупки через `ysdk.payments` (консумирование, валюта из SDK), облачные сохранения `player.setData` со слиянием по максимуму (обязательно при покупках);
- размер архива ≤ 100 МБ: сейчас музыка 158 МБ → либо музыка с нашего сервера (адрес в CSP черновика по заявке), либо перекодировать (AAC ~112 кбит/с ≈ 88 МБ всего);
- без внешних ссылок, баннера установки и service worker в этой сборке; долгое нажатие не выделяет текст;
- отдельная команда сборки `npm run build:yandex`, архив с `index.html` в корне.
Готово, когда: черновик проходит самопроверку по требованиям, игра работает во фрейме Яндекса на Android, iOS и ПК. **Нужно от владельца:** аккаунт разработчика, решение по музыке (сервер или перекодирование).
