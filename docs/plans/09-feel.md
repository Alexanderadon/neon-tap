# 09 — Feel: темы треков, фон в такт музыке, живое меню

## Цель

Каждая песня выглядит по-своему, фон дышит вместе с музыкой, меню не статичное.
Всё — без новых зависимостей, без аллокаций в кадре, без `shadowBlur` в кадре.

## Что делаем

1. `shared/lib/render/themes.ts` — 8 тем по жанру (synthwave, chiptune, lofi, rock, orchestral,
   jazz, techno/dnb, ambient/acoustic). `themeFor(genre?, id)`: по жанру, иначе детерминированно
   по хешу id. Тема = фон `[top, bottom]`, цвета полос, акцент HUD, цвет свечения, мотив
   (`grid | rings | bars | haze`). Synthwave = текущий вид игры один в один.
2. `Renderer` принимает тему: цвета полос вместо `LANE_COLORS` (спрайты, ресепторы, лучи,
   частицы, кольца), градиент фона статического слоя, акценты HUD.
3. Фон в такт музыке (всё за `fxLevel === 'full'`):
   - `BeatCursor` (`shared/lib/audio`): курсор по `chart.beats`; на каждой доле
     `renderer.beatFeedback(strength)` (сильная доля — каждая 4-я). Кольцо + вспышка горизонта,
     затухание ~300 мс.
   - `AudioEngine.spectrum(out)`: 32 лог-полосы из `AnalyserNode` в один переиспользуемый
     `Uint8Array`; `spectrumBands()` — чистая функция с тестами.
   - Зеркальный эквалайзер за полем из предрендеренного glow-спрайта, alpha ≤ 0.35,
     сглаживание attack/release.
   - Мотив темы: линии горизонта в такт (grid), концентрические кольца (rings), плывущие
     столбы (bars), дымка (haze) — несколько fill/drawImage в кадре.
4. Меню (только CSS, `prefers-reduced-motion`): мерцание логотипа при загрузке, появление
   слогана, карточки по очереди (`--i`), hover/press свечение + наклон, ползущая неоновая
   сетка, вход экрана 250 мс на `Screen`.
5. Карточка трека — полоска из 5 цветов темы.
