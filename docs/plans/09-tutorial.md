# Фаза 9 — Обучение (первая минута)

Интерактивный туториал: за ~60 с игрок пробует тап, холд, слайд, дробь, круги и смену полос
на настоящем игровом холсте, без сердец и без провала.

## Карта — `public/charts/tutorial.json`

Ручная карта `id: tutorial`, `title: Обучение`, ★1 на сетке долей «Apparatus Overlord» (CC0, 120 BPM):
bpm / offset / beats / audio / duration / license / sourceUrl / artist скопированы из
`apparatus-overlord.json`. Каждая нота лежит ровно на доле (16-е — на четвертях доли).

| Доли | Шаг | Ноты |
|---|---|---|
| 0–10 | вступление | нет |
| 10–17 | тап | 4 тапа в полосе F по долям |
| 20–29 | все полосы | тапы по разным полосам (восьмые, потом D/K) |
| 32–43 | холд | 3 холда ≥ 1 доли |
| 46–53 | слайд | F → J, J → F (во время слайда больше ничего) |
| 56–63 | дробь | 2 дроби × 3 удара за 2 доли (3 уд/с ≤ 6) |
| 66–70 | круги | окно из 3 кругов 1-2-3 зигзагом, полосных нот нет |
| 76 | смена полос | 4 → 3, пауза ≥ 2 доли до смены |
| 77–116 | свободная игра | тапы, холд, слайд, дробь, аккорд |

Ограничения: ≤ 3.5 нот/с, не больше двух вещей одновременно (правило двух больших пальцев).
Сессия заканчивается через 1.5 с после последней ноты (`GameSession.endTime`), а не по длине трека.

## Код

- `features/tutorial` — сценарий подписей в долях (`TUTORIAL_PLAN`), `buildScript(beats)`,
  `captionAt(script, songTime)`, `stepProgress`; тесты: поиск подписи и проверка карты
  (сетка 16-х ± 30 мс, дроби ≤ 6/с, слайды в соседнюю полосу, плотность, пустое окно кругов,
  пауза перед сменой полос, каждая нота внутри шага своей механики).
- `widgets/tutorial-overlay` — карточка над холстом: SVG-иконка механики с CSS-анимацией,
  подсказка (клавиши на десктопе / пальцы на тач), точки шагов, прогресс шага,
  «Отлично!» после первого попадания в шаге, «Пропустить». Pointer events сквозные,
  кроме кнопки.
- `pages/tutorial` — `GameCanvas mode="tutorial"` + оверлей; финиш / пропуск / выход →
  `settings.tutorialDone = true` → меню.
- `GameCanvas` — проп `mode` (`play` | `tutorial`): в туториале `noFail`, `hideHearts`,
  без автоподстройки задержки и без сохранения результата; `onEvent`, `onTime` (~10 Гц из
  RAF-цикла, без аллокаций), `onExit`.
- `GameSession` — опции `hideHearts` (сердца не рисуются: `maxHearts = 0`, эффекты потери не
  срабатывают) и `onTime`.
- Роутер: экран `tutorial`; меню — ghost-кнопка «Обучение»; `App` открывает туториал один раз
  после калибровки (`settings.tutorialDone`, санитизируется, хранится в localStorage).
- Словарь: блок `// --- tutorial ---` в `shared/i18n/ru.ts`.

## Проверка

`npx tsc -b`, `npx vitest run`, `npm run lint`, `npm run build`. Обычная игра (`mode="play"`)
не меняется.
