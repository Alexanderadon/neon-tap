# Фаза 10 — Меню: неоновая консоль

## Проблема

Старое меню — центрированная колонка одинаковых карточек: логотип, три кнопки, панель целей, список из 32 карточек. Палитра нравится, компоновка «как у всех».

## Решение

Портретная «неоновая консоль», телефон в приоритете:

1. **Hero** во всю ширину сверху — трек дня (или выбранный в ленте трек): его обложка увеличена и размыта на фоне, скан-линии только здесь, тонкие неоновые линейки, заголовок в Unbounded, цифры моноширинным шрифтом, ★ сложности, лучший ранг, огромная круглая кнопка PLAY с кольцом-пульсом на 120 BPM. Вторичные действия «Обучение» и «Своя музыка» — тут же.
2. **Лента** — горизонтальная прокрутка больших квадратных обложек со snap (на телефоне видно три), над ней чипы жанров (из каталога) и переключатель порядка «по сложности / по названию / новые». Тап по карточке выбирает трек в hero, повторный тап — играет. Закрытые треки — замок и «★ N», трек дня — лента «день».
3. **Док** снизу (sticky, safe-area) с пятью рукописными SVG-иконками: Играть (к ленте), Магазин (`navigate('shop')`, экран из потока shop), Цели (к панели целей), Рекорды (история выбранного трека), Настройки.
4. **Десктоп ≥ 900 px** — две колонки: hero слева (sticky), лента становится сеткой в три колонки справа, док — верхняя панель.
5. Движение: карточки масштабируются при фокусе/выборе, кольцо PLAY пульсирует в 0.5 с (120 BPM), всё выключается при `prefers-reduced-motion`.

## Код

- `widgets/track-list/lib/reel.ts` — чистая логика ленты (жанры, порядок, шаг по стрелкам), тесты в `reel.test.ts`.
- `widgets/track-list/model/` — `useCatalogState` (звёзды, открытия, трек дня), `usePlayTrack`, `useMenuPrefs` (жанр/порядок в localStorage).
- `widgets/track-list/ui/TrackHero.tsx`, `TrackList.tsx` (лента, публичный API `onRecords` сохранён + `selectedId`/`onSelect`), `icons.tsx`.
- `pages/menu` — компоновка, док, `DockIcons.tsx`, `menu.css`.
- `shared/lib/router` — `'shop'` в `Screen`; `App.tsx` — временный case на меню до появления `ShopPage`.
- `shared/i18n/ru.ts` — блок `// --- menu ---`.

## Проверка

`tsc -b`, `vitest run`, `npm run lint`, `npm run build`. Раскладка от 360 до 1440 px — по CSS-решениям (clamp, контейнерные проценты, `dvh`), без браузера в этом потоке.
