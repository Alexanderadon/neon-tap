# Фаза 5 — Автогенератор карт ⭐

## Задачи
- [x] `shared/lib/analysis/fft.ts` — radix-2 FFT, окно Ханна, без аллокаций.
- [x] `OnsetDetector.ts` — spectral flux (log-компрессия, half-wave rectify), окно 1024 / hop 512, адаптивный порог = скользящее среднее ±10 кадров × 1.5, минимальный интервал 50 мс, доли энергии по полосам 20–250 / 250–2000 / >2000 Гц.
- [x] `BpmEstimator.ts` — автокорреляция огибающей flux по лагам 60–220 BPM, бонус за кратные лаги, параболическая интерполяция, фолд в 90–180, фаза сетки.
- [x] `ChartGenerator.ts` — квантование к 1/8 (Easy) / 1/16 сетке, фильтр силы по перцентилю, минимальный интервал, кап плотности 3 / 6 / 10 нот/с, полосы по доминирующей частотной полосе, правило «≤ 2 подряд в одну полосу», аккорды и холды на Normal/Hard, детерминированный PRNG.
- [x] Web Worker (`features/generate-chart`) с прогрессом по стадиям; файл не покидает браузер.
- [x] `widgets/song-drop-zone` — drag&drop / file input → прогресс → выбор сложности.
- [x] Тесты: синтетический сигнал — детекция ≥ 90 % в ±30 мс, BPM 128 ± 2, правила раскладки, детерминизм.
- [x] Тот же код запускается в Node (`scripts/generate-charts.ts`) для встроенных треков.

## Готово когда
Любой MP3 → карта за 5–15 с. Факт: ~1.2 с на 150-секундный трек в Node, в браузере сопоставимо.
