# NEON TAP

[![CI](https://github.com/Alexanderadon/neon-tap/actions/workflows/ci.yml/badge.svg)](https://github.com/Alexanderadon/neon-tap/actions/workflows/ci.yml)

**Играть: https://neon-tap-virid.vercel.app** — открывается в браузере, без установки, работает на телефоне.

Браузерная ритм-игра на 3–5 полос, которая **сама генерирует карту нот из любого MP3**. Игрок кидает файл в окно — движок за ~1–2 секунды прогоняет его через собственный FFT, spectral-flux детектор ударов, автокорреляционную оценку темпа и трекер долей, ставит ноты на реальные удары музыки и добавляет механики по её структуре: холды и слайды на тянущихся звуках, дроби на сбивках, круги на старте припева, смену числа полос по фразам. Одна карта на песню — сложность (★ 1–10) определяет сама песня. Файл не покидает браузер.

Игровой цикл, аудио, судейство и анализ сигнала написаны с нуля на TypeScript поверх Web Audio API и Canvas 2D. React отвечает только за меню. Рантайм-зависимости: `react`, `react-dom`.

## Технические решения

### 1. Тайминг — только от аудиочасов

Единственный источник времени для нот — `audioContext.currentTime`. `requestAnimationFrame` рисует, но никогда не решает, попал игрок или нет.

```ts
// src/shared/lib/audio/Clock.ts
songTime() { return audioNow() - startTime - userOffset; }
```

Почему не `performance.now()`: у аудиокарты свой кварц. Разница с системными часами накапливается и за 30–60 секунд даёт слышимый рассинхрон. Аудиочасы не дрейфуют относительно самих себя по определению. Таймстампы событий клавиатуры/тача переводятся из домена `performance.now()` в аудиовремя с поправкой на возраст события, чтобы задержка JS-обработчика не засчитывалась игроку.

### 2. Автогенерация карт

```
AudioBuffer → моно 22 050 Гц → STFT (Hann 1024, hop 512)
  → spectral flux по полосам 20–250 / 250–2000 / >2000 Гц → онсеты
  → автокорреляция огибающей 60–220 BPM → темп (+ проверка октавы)
  → трекер долей (DP, Ellis 2007): доли на реальных ударах, ровный шаг, без дрейфа
  → сетка 16-х между долями: сила удара, полоса частот, сустейн на каждом слоте
  → ноты «по слуху»: слот получает ноту, если это локальный пик удара, заметный на фоне фразы
    (приоритет долям и восьмым, лимит нот по интенсивности такта, ≤ 3.5 нот/с, два пальца)
  → холды на тянущихся звуках (часть — слайды в соседнюю полосу), дроби на сбивках и стримах припева,
    окна кругов на старте припева, спеллы, аккорды на сильных долях
  → секции с числом полос 3 / 4 / 5 по энергии фразы → одна карта, ★ 1–10
```

Весь пайплайн — `src/shared/lib/analysis`, без DOM, поэтому один и тот же код работает в Web Worker для пользовательских файлов и в Node для встроенных треков (`npm run assets:charts`). На синтетическом сигнале детектор находит ≥ 90 % ударов в окне ±30 мс, трекер долей попадает в каждый клик с точностью 30 мс, темп 128 BPM определяется с точностью ±2 (тесты в `analysis.test.ts`). 150-секундный трек анализируется за ~1.5 с.

Геймплей поверх этого: тапы, холды, **слайды** (палец переезжает в соседнюю полосу), **дроби** (несколько нажатий за одну ноту, не быстрее 6/с), **круги** в стиле osu! (тап по кругу на экране, в окнах без обычных нот), 5 сердец (промах −1, серия из 25 попаданий +1, ноль — провал), спелл «замедление» замедляет и музыку, и ноты (playbackRate + tape-эффект), спелл «сердце» +1 жизнь, тач-помощь на телефоне (нажатие до 0.4 с раньше засчитывается), автоподстройка задержки по попаданиям игрока, скорость нот — своя у каждой песни (3.5 доли на подлёт). Число полос меняется по фразам: разделители и рецепторы физически разъезжаются или сливаются.

### 3. Рендер: 60 FPS без аллокаций в кадре

- Свечение нот, лучей и частиц предрендерено в offscreen-canvas при инициализации; в игровом цикле `shadowBlur` = 0. На мобильных `shadowBlur` в кадре роняет FPS в 3–4 раза.
- Статика (полосы, хит-лайн, виньетка) — отдельный слой, рисуется одним `drawImage`.
- Ноты — пул на 2000 объектов с курсорами по полосам; частицы — `Float32Array` (SoA) на 300 элементов.
- Дебаг-оверлей (настройки → FPS) показывает fps, худший кадр, число видимых нот и латентность вывода.

### 4. Калибровка задержки

Задержка аудиовывода: десктоп 20–60 мс, Android 80–200 мс, Bluetooth до 300 мс. При первом запуске метроном 120 BPM планируется look-ahead-планировщиком на аудиочасах; игрок тапает 16 раз; медиана отклонений (устойчива к выбросам первых тапов) становится `audioOffsetMs`. Ручной слайдер −300…+300 мс в настройках.

### 5. Что добавила v2

- **Обучение** — интерактивный первый запуск (после калибровки, один раз; кнопка «Обучение» в меню): рукописная карта `public/charts/tutorial.json` на сетке долей Apparatus Overlord ведёт через тап → все полосы → холд → слайд → дробь → круги → смену полос → финал; подписи-шаги с анимированными SVG-иконками и подсказками для клавиатуры и пальцев, без сердец и провала (`features/tutorial`, `widgets/tutorial-overlay`, `pages/tutorial`).
- **Прогрессия** — первые 5 треков открыты, дальше пороги по звёздам; **трек дня** (детерминированно по дате) даёт +1 ★ раз в день и копит серию; **8 целей** с наградами в ★ (панель в меню, строка на экране результата). Сохранение v3 с миграциями (`entities/progress`).
- **Рекорды** — история попыток с спарклайном точности на каждой карточке («Рекорды»), опциональная онлайн-таблица (см. ниже).
- **Экран результата** — таймлайн судейств пишется в типизированные массивы прямо в игровом цикле, из него: полоса «где промахи» по всей песне, график точности/комбо, лучшая серия и слабое место, **повтор лучшего момента** (мини-поле на canvas) и карточка 1080×1350 для «Поделиться» / копирования (`entities/score/lib/resultStats`, `widgets/result-breakdown`).
- **Мобильная версия** — safe-area (челка и home-индикатор), тач-зоны с подсветкой пальца, мультитач через `PointerLanes`, подсказка «поверни телефон» с паузой, **экономный режим** (авто: FPS < 45 три секунды → меньше частиц и фоновых эффектов), PWA-манифест и иконки. Чек-лист — `docs/mobile-checklist.md`.
- **Контент** — 30 треков в 12 жанрах, жанр в реестре и в карте, **процедурные обложки** (SVG из хэша id + палитра/мотив жанра, `entities/track/ui/TrackCover`).
- **Ощущение** — визуальная тема на трек (по жанру или детерминированно по id: палитра полос, акцент, мотив фона), фон синхронизирован с музыкой (пульс на долях из карты + спектр из AnalyserNode, один read на кадр), анимированное меню и карточки.

## Архитектура

Feature-Sliced Design: `app → pages → widgets → features → entities → shared`. Направление импортов и публичные API слайсов проверяются `eslint-plugin-boundaries` и `scripts/check-fsd.mjs` в CI.

```
src/
├── app/         роутер экранов
├── pages/       menu · game · result · calibration · settings · custom · tutorial
├── widgets/     track-list · goals-panel · game-canvas · tutorial-overlay · result-breakdown · history-panel · online-leaderboard · song-drop-zone · audio-gate · calibration-meter · settings-panel
├── features/    play-chart · generate-chart · calibrate-offset · save-result · submit-score · track-progress · voice-feedback · tutorial
├── entities/    track · chart · score · progress · history · settings · play-session
└── shared/lib/  audio · analysis · render · input · store · router
api/             scores.ts — Vercel serverless-функция онлайн-таблицы (Node, без зависимостей); api/_lib — чистые хелперы с тестами
```

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 226 юнит-тестов (vitest)
npm run lint       # eslint + проверка FSD
npm run build
```

Ассет-пайплайн (нужен только для пересборки контента): `npm run assets:music`, `assets:sfx`, `assets:voice`, `assets:charts`, `assets:licenses`. Деплой: `bash scripts/deploy-fresh.sh <имя-проекта>` (локальная сборка → новый проект Vercel → перенос домена).

### Рекорды и онлайн-таблица

История попыток (счёт, точность, ранг, тренд) хранится локально в `localStorage` и открывается по ссылке «Рекорды» на карточке трека. Онлайн-таблица — опциональна: `api/scores.ts` хранит топ-100 на трек в Upstash Redis через REST API. Чтобы включить, задайте в проекте Vercel переменные `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN` (Upstash → база → REST API). Без них функция отвечает `{ enabled: false }`, и секция «Онлайн-рекорды» просто не показывается. Ник спрашивается один раз на экране результата и меняется в настройках.

## Лицензии на музыку

Все 30 встроенных треков (синтвейв, техно, чиптюн, лоу-фай, рок, оркестр, джаз-фанк, драм-н-бейс, эмбиент, акустика, этника) — **CC0 1.0** с OpenGameArt.org, авторы и ссылки в [`public/music/LICENSES.md`](public/music/LICENSES.md). Звуковые эффекты — CC0-сэмплы из паков Kenney (удары по нотам — round-robin из 5 вариаций, чтобы не было «пулемёта»). Озвучка — нейросетевые голоса ru-RU Dmitry / Svetlana, выбираются в настройках. Реестры источников — `assets-src/tracks.json` и `assets-src/sfx.json`, из них скриптами генерируются и файлы, и отчёт по лицензиям.

Пользовательские файлы для «Своей музыки» обрабатываются в браузере и никуда не отправляются.
